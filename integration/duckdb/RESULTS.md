### Filter + GROUP BY on token ids, decode only the output

| query | ms | output rows | detokenize() rows | token_like rows |
|---|---:|---:|---:|---:|
| `token_then_decode_10` | 15.2286 | 10 | 10 | 672,451 |
| `decode_all_then_like` | 25.1463 | 10 | 718,561 | 0 |
| `raw_text` | 9.1471 | 10 | 0 | 0 |

Verified: pass. The token query orders ties by the BLOB (token-id bytes), the raw query by text, so the URLs inside a tie may differ; verification checks every decoded URL's count against the raw-text GROUP BY and that the 10 counts are the 10 largest.

```sql
SELECT detokenize(encoded_url) AS url, n FROM (
  SELECT encoded_url, count(*) AS n FROM urls WHERE token_like(encoded_url, '%.php')
  GROUP BY encoded_url ORDER BY n DESC, encoded_url LIMIT 10)
```
